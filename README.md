# daily-data-aggregator
Суть автоматизации: Скрипт автоматизирует рутинную задачу менеджеров или аналитиков по сбору данных из разных источников (например, API курса валют, выгрузки CSV из CRM). Он по расписанию агрегирует данные, строит графики, формирует PDF-отчет и автоматически рассылает его по заданным email-адресам.
